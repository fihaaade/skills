# Example index

Use this index to select quality anchors by capture register. Each entry names the reusable grammar and the axes most worth changing in the anchor delta. Read the entries as material behavior, never as compositions to reproduce.

The background is a flat cyan wash with one faint magenta bruise. Preserve the grid-over-skin texture and the cold flat backdrop; vary the body part, crop direction, and warm-mass placement.

Preserve the object-as-portrait scale and the grid legibility; vary the object, viewing angle, and background luminance.
