# Phosphor Relay

拍屏幕，不拍现场。

这是一个图像风格技能：它把任意题材编排成「一台相机对着一块正在播放转播画面的发光屏幕」所拍下的一帧，并输出对应的图像生成提示词与图像。

## 视觉方向

- **二手光**：画面里唯一的光源就是屏幕本身。没有阳光、没有灯、没有闪光。
- **网格即材质**：荧光点阵（RGB 条纹 / 孔栅 / 荫罩点三联）在全画幅持续可见，覆盖约 25%–60%。它是画面的皮肤，不是叠加的滤镜——高光里有，死黑里也有。
- **冷场 + 一块暖**：青蓝统治 60%–85% 的色场；红/品红/橙作为**单一连续的暖色块**占 3%–15%（一件球衣、一块广告牌、一片看台、一条跑道）。绝不把暖色撒得到处都是。
- **两端曝光失效**：高光晕开融成一团（白球衣糊成无边缘的整块），暗部塌成纯黑（帽衫下的脸是实心黑洞）。信息全在中间调。
- **只有网格是锐的**：主体一律软焦、失焦、拖影或插值糊掉。光学锐度只属于荧光结构。每一帧都必须解决这个矛盾。
- **非决定性瞬间**：拍的是动作**周围**——走路、等待、背影、庆祝之后、空看台、一只鞋、一只手。永远不拍进球、不拍射门、不拍最高点。
- **场景内文字保留，叠加层禁止**：球衣上的名字号码、广告牌赞助商字样、球鞋上的手写体、招牌——这些本来就在镜头前，保留，但被网格打碎、被过曝吞掉，只认得出片段。禁的是合成图层：比分、计时器、台标、字幕条、水印。
- **没有画框家具**：无边框、无 mockup、无屏幕边框、无房间环境。屏幕撑满整幅。
- **匿名的身体**：主体读作「一个人形」而非「某个人」。脸被裁掉、转开、糊掉或塌成黑洞。

## 两个模式

**Treat 是主模式** —— 这套东西本质是一个材质系统，任何照片都能过一遍。

- **Treat**：给一张照片，保留它的主体、构图、裁切、瞬间，只施加材质系统。取景族、尺度、时刻从照片里读出来而不是选出来；只有信号状态、色彩事件、焦点行为、网格行为还是自由选择。输出必须还认得出是同一张照片。
- **Originate**：不给照片，九轴全选，从简报造一帧。

给了照片就默认 Treat。

## 五个取景族

| 族 | 适合 | 尺度 |
| --- | --- | --- |
| Close signal | 面孔、后颈、手、球鞋、布料、单个物件 | 主体占 60%–100% |
| Field action | 对抗、奔跑、争夺空间、2–5 人 | 人物占高度 25%–60% |
| Held still | 背影、等待、走出通道、独自站立 | 人物占 20%–50%，大片空场 |
| Crowd and structure | 看台、人群、球场碗、航拍几何 | 无单一主体，纹理即主体 |
| Dissolved | 多帧重影、水平撕裂、无法辨认的色块 | 主体故意不可读 |

## 变化引擎

生成前每轴各选一个：**画框结构**（单帧 / 均分双联 / 偏置双联 / 上下叠）、**信号状态**（稳定 / 重影 / 拖抹 / 撕裂 / 解体）、**色彩事件**（纯青 / 青+红块 / 草场绿 / 过曝泛白 / 死黑压暗）、**焦点行为**（网格锐 / 双软 / 塌陷）、**时刻**。

双联的两块必须在取景族或信号状态上不同；两块相似即判失败。

## 关键防线

`SKILL.md` 里有一节 **Banned wording**，这是整个技能最重要的部分。以下措辞会把模型拽离这个风格，禁止进入提示词：

- `film grain` / `35mm` / `kodak` / `analog film` —— **这是发光的屏幕，不是曝光的胶片**。一提胶片，网格就没了。
- `subtle texture` / `light grain` / `scanline overlay` —— 网格是结构性且主导的，永远不是"轻微"，也永远不是"叠加层"。
- `glitch art` / `datamosh` / `vaporwave` / `neon` / `cyberpunk` —— 这里的劣化是物理的、意外的，不是设计出来的。
- `sharp` / `crisp` / `4K` / `HDR` / `ultra detailed` —— 主体天生低保真。`sharp` 只能用在网格上。
- `warm` / `golden hour` / `sepia` —— 色场是冷的，暖只以单一色块存在。
- `dramatic` / `epic` / `decisive moment` / `action shot` —— 时刻必须是平淡的。

另外：`soft`、`blurred`、`low contrast` 只能作用于主体，不能描述网格，也不能描述整张图——两端曝光失效本身是高反差。

## 目录结构

- `SKILL.md`：完整技能说明（英文，供模型执行）
- `EXAMPLES.md`：试跑清单——快速上手、逐轴覆盖、压力测试，以及跑完之后该调什么
- `references/example-index.md`：按取景族索引的质量锚点，含每条的「保留什么 / 改变什么」
- `references/repair-playbook.md`：16 条失败信号 → 提示词修正对照表
- `assets/examples/`：10 张参考帧

## 使用

```text
用 $phosphor-relay-style 做一张关于「雨后空荡球场」的图
```

工作流第 3 步会从 `example-index.md` 选 1–2 个锚点，记录「保留 3 个不变量 + 改变 3 个轴」，再编译成四段式提示词。范例只做质量锚点，不做构图模板——有一条 gate 专门检查成品是否像范例的复制品。

第 7 步会在全尺寸和缩略图两个尺度检查，并要求**在高光区、暗部、中间调三处分别放大确认网格存在**。只在中间调有网格的，判失败。

## 关于素材

参考帧源自足球转播画面的屏幕重摄。本技能规定的是**主体无关的视觉处理系统**——网格材质、色彩治理、曝光失效、构图语法——不绑定任何具体人物、球队或赛事。技能明确禁止生成可辨认的真实个人肖像；若请求指名真人，工作流第 1 步会将其转为同场景下的匿名人形。
