# 星芒圣物 · Starlit Relic v1

把一件物体从它的世界里取出，悬在夜色里，然后把它当作一颗星来打光。

## 风格是什么

- 3:4 竖幅，底色是从近黑到钴蓝的一整块纵向渐变，铺满胶片颗粒，没有地面、没有地平线、没有第二个东西。
- 画面里只有一件圣物（王冠、篮筐、山羊摆件、神庙、头盔、船、战锤、月桂环、斗兽场、三根石柱），悬浮在画面中上部，占宽度的 25–50%，微微倾斜；也可以是一个严格背面的人站在属于他的机器上，身后升起粒子喷泉。
- 物体本身大半在暗部，只有少数几个热点：星光滤镜的星芒、闪粉、光晕；星芒必带一侧品红一侧青蓝的色散。
- 冷场暖物：钴蓝的夜对金铜粉红的高光。
- 一切像胶片：颗粒、光晕、色差、微微发软，绝不是数字光效。

## 怎么调用

```text
用 $starlit-relic-v1 做一张王冠。
把这张球鞋照片做成星芒圣物风格。
三根石柱在坠落中碎掉，星芒圣物。
```

可附加：物体、姿态（悬停 / 漂移 / 坠落 / 上升）、光的语法（星芒 / 闪粉 / 光晕 / 边缘光）、是否要一行小字。

## 变更记录

- **1.4.0 · 风格而非内容**：解除三处过拟合——人物朝向自由（背面与不见脸是参考图的偶然内容，不是风格不变量，脸可以出现）；粒子词汇解锁（拖尾/尘云/流苏/喷泉自由组合、括号场景只是出处不是归属，剂量规则替代单选规则）；光效改为「主声部 + 自由叠加」。人物的标准帧锚定为赛车那张：粒子、尘云、简单的自色发光。

当前版本 **1.4.0**（frontmatter `version` 字段）。规则语义变化升次版本号，仅文档/打包调整升修订号；首轮验收修正（画内边距、尘云密度、建筑上限等）为 1.2.0。

- **1.3.0 · 人物光则**：人物在任何语法下发出自身主色调的光晕、披一层克制的闪粉壳（可数、不成涂层）；「物得星芒，人得辉光」——星芒只落在物体上，人的高光一律 CCD 式柔和辉光。新增「遮蔽的凝视」受限语法（装备遮脸 ≥70%、眼中暖色辉光、精确触发词），未遮蔽的正面仍然拒绝。

- **1.2.1 · 纯文字化**：移除全部参考图片，风格完全由规则 + 逐帧档案承载；SKILL.md 增加「标准帧」文字画面，流程去掉附参考图一步。

- **1.1.0 · 第二轮校准（+5 张参考图）**：新增 day-for-night 中蓝场变体与「明暗关系」显式选择（暗物亮场）；新增单闪光语法（战锤）与燃烧构件（船帆）；新增粒子伴随菜单（星尘拖尾 / 尘云 / 悬浮流苏 / 粒子喷泉，至多一种、限一处）；新增「人物与圣物」主体语法（严格背面、不见脸、允许一条纯黑前景带——全 skill 唯一的地面例外）；构图范围放宽到宽 25–50%、中心高 40–55%（大型建筑 38–45%）。
